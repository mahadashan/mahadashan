## About

I am a computer science student at **Riphah International University, Lahore** (2023–2027, CGPA 3.62) with a focus on offensive security and practical software development.

My current interests include web application security, digital forensics, malware analysis, and security automation. I also build full-stack applications and document my work through technical write-ups, detection rules, and penetration testing reports.
